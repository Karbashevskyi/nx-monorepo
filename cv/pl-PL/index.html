Thiis

2021 - obecnie

OpenSource

Założyciel

  • Stworzyłem projekt open source Thiis – pakiet dla czystego JavaScriptu umożliwiający łatwą i zrozumiałą walidację danych.
  • Motywacja: potrzeba precyzyjnej i jednoznacznej walidacji danych, aby uniknąć błędnej interpretacji przez system i programistów, oraz prostego i czytelnego kodu walidacji.
  • Funkcjonalności:
    • Typowanie dla lepszego wsparcia TypeScript.
    • Prosta składnia walidacji, np. is.object(variable) zamiast złożonych warunków.
    • Łączenie różnych walidacji, np. is.object_not_empty(variable).
    • Obsługa metod globalnych, np. is.HTMLElement(variable).
    • Wszystkie metody zwracają wartości logiczne, co eliminuje błędy walidacji.
    • Rdzeń biblioteki wykorzystuje proxy JavaScript do dynamicznego wywoływania metod na podstawie nazw podanych przez programistów.
    • Przykład:

      Zamiast złożonego kodu:

      if(typeof variable === 'object' && variable !== null && !Array.isArray(variable) && Object.keys(variable)?.length)

      użyj prostszego i czytelniejszego:

      if (is.object_not_empty(variable))

  • Plany: narzędzie CLI konwertujące polecenia na kod inline dla szybszego działania programu.
  • Promocja projektu: aktywna promocja na medium.com i dev.to w celu zwiększenia popularności.

https://karbashevskyi.github.io/thiis/docs/Introduction/
